What feeds each factor

  • Matchup: PPR points the opponent has allowed per game to that position, weeks 1–10.
  • Game environment: implied team total, minus a penalty outdoors for wind 15+ mph, heavy rain or sub-30°F (doubled for kickers; helps DEF).
  • Season average: PPR points per game, weeks 1–10.
