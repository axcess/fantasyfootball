Scoring weights

Each factor is a 0–100 percentile against starting-caliber players at the same position. Move a slider and every score, the lineup and the waiver list recompute. Out, Doubtful, IR, PUP, suspended and bye-week players stay on the bench at any score.

What feeds each factor
  • Opportunity: last 3 games. RB: carries + 1.5×targets + 3×red-zone looks + snap share. WR/TE: 1.5×targets + carries + 3×red-zone targets + snap share. QB: attempts + 2×rushes + 3×red zone. K/DEF: Sleeper's weekly projection.
  • Recent form: PPR points per game over the last 3 games played.
  • Matchup: PPR points the opponent has allowed per game to that position this season.
  • Game environment: implied team total, minus a penalty outdoors for wind 15+ mph, heavy rain or sub-30°F (×1.5 for kickers; weather helps a DEF).
  • Season average: PPR points per game this season.

Caveats
  • The weights are your own starting point, not a proven model. Tune them on the Model tab after a few weeks.
  • Projections are estimates, and late scratches still happen.
  • Practice status comes from the NFL.com report as of the last data refresh. Re-check on Sunday morning.
  • Depth-chart changes compare Sleeper's depth order against last week's saved snapshot.
  • Odds are read-only inputs. This site has no betting features.
